# UI and UX plan

The primary screen will be a job inbox optimized for quick review. The current Web app is a foundation shell using Material UI. The workflow begins with the **Overview**, then **Job Inbox**, **All Jobs**, **Saved Jobs** and **Vacancy Details**. Configuration and operations include **Search Profiles**, **Companies**, **Sources**, **Execution History**, **AI Providers** and **Resource Usage**.

A result shows title, company and employer location, separately from Germany-based remote eligibility. Show relevant technologies, stated language requirements, outcome, concise explanation, blockers, uncertainties, application method, source and discovery date. Offer save, dismiss and export after human review. Preserve employer instructions and original descriptions where permitted, label optional translation and give access to the original. Use a neutral presentation for unknown fields and expose the distinction between a source quote and a model's interpretation.

Use responsive Material UI layouts, readable typography, accessible names, keyboard navigation, visible focus and contrast in both color schemes. Pair status color with text. Keep actions reachable on mobile. Provide informative loading, empty, partial and error states, preserve selections where practical and offer recovery. Test normal, no-results and failure flows at narrow and wide sizes.

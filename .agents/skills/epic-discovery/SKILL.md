# Epic Discovery

Read the [roadmap](../../../docs/roadmap.md), product vision, accepted ADRs and current code before using GitHub Issues and CI to assess execution status. Use historical notes only as context. Compare actual implementation, issue dependencies and current phase exit criteria. Record contradictions and assumptions.

Use the [epic template](../../../docs/templates/epic-discovery.md). Investigate the user problem, alternatives (including keeping existing behavior), real dependencies, architecture, security, source permissions, and costs. Cite primary sources for changing constraints. Identify shippable phases, non-goals, observable success and open decisions. For a progress inquiry, state what is done, in progress or blocked and why. Finish with findings and a recommendation. Research does not authorize implementation, filing issues, or creating a branch.

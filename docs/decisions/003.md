# ADR-003: Firestore adapter and local-first emulation

**Status:** Accepted

## Context

Persistence needs simple managed document access while unit tests avoid cloud dependencies.

## Alternatives considered

A directly imported SDK leaks vendor types across modules. An additional database adds infrastructure and duplicated modeling. Production integration tests require credentials and cost.

## Decision

Use a dedicated server SDK adapter and choose Firestore Standard edition in Native Mode for the intended production design. Run daily development and integration tests with separate synthetic emulator projects.

## Consequences

Design queries and indexes per access pattern and validate regional compatibility before deployment. Emulator checks cannot certify IAM, indexes, limits or production performance.

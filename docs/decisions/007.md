# ADR-007: Codex skills and architecture verification

**Status:** Accepted

## Context

The repository needs repeatable planning and code review with traceable evidence.

## Alternatives considered

Running Dark Factory requires its runtime and external process integration. Review-only architecture guidance can miss forbidden edges.

## Decision

Use repository-local Codex skills, original forms where licensing permits, standalone templates and issue validation. Reuse the pinned TypeScript compiler API to check actual source imports and cycles, avoiding another package.

## Consequences

Owner approvals, revision integrity and issue-to-PR closure are procedural. The graph has defined source scope. Vendor skill licenses and provenance are tracked in the inventory.

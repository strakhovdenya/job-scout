# Roadmap

| Milestone                                                      | Scope and status                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **M0 — Data Source Feasibility Study**                         | **Next, planned.** Verify Arbeitnow, Jobicy, Greenhouse Job Board API, Lever Postings API, Ashby Job Posting API, Personio XML, permitted DOU RSS and other documented sources. Check German and Ukrainian coverage, full descriptions, languages, geographical limits, links, application email coverage, stability, and permission to collect, store, display, retain, redistribute and process with AI. Source approval precedes implementation. |

See the M1.1 change and its CI for evidence.                                                                                                                                                                                             |
| **M2 — Job Ingestion and Normalization**                       | Planned. Implement validated adapters, company/source configuration, normalization, deduplication, persistence and vacancy lifecycle.                                                                                                                                                                                                                                                                                                               |
| **M3 — AI Screening and Provider Fallback**                    | Planned. Configurable candidate profiles, ADK screening, language and remote eligibility, application details, provider integrations, quota-aware routing and evaluations with emphasis on false negatives.                                                                                                                                                                                                                                         |
| **M4 — Job Inbox and Search Profiles**                         | Planned. Personalized inbox, profiles, vacancy details, saved/dismissed results, source management, execution history and resource usage.                                                                                                                                                                                                                                                                                                           |
| **M5 — Google Cloud Infrastructure and Scheduled Execution**   | Planned. Owner-authorized project and billing setup, Terraform bootstrap, Cloud Run Service and Jobs, Firestore, IAM, scheduling and production acceptance.                                                                                                                                                                                                                                                                                         |
| **M6 — JobFlow Integration and Operational Reliability**       | Planned. Versioned export, JobFlow integration, recovery, monitoring, resource controls and justified notifications.                                                                                                                                                                                                                                                                                                                                |
| **M7 — Portfolio Release and Evaluations**                     | Planned. Evaluation and security results, measured performance and cost, architecture write-up, demo mode and portfolio presentation.                                                                                                                                                                                                                                                                                                               |

# Prd

Read the approved discovery scope, product vision, roadmap, affected code and relevant ADRs. Confirm dependencies and write down unknowns. Resolve material scope forks with the owner. Use the [canonical PRD](../../../docs/templates/prd.md) and preserve every epic exclusion and criterion. Mark added criteria and explain their origin.

Describe observable behavior, expected outcomes, constraints, edge cases and failure scenarios. Keep implementation choices for the technical plan. State invariants and actual variation points. In epic mode propose candidate slices mapped to criteria and optionally recommend an integration branch. Verify scope and traceability, then present the draft for explicit owner approval of that revision. An approval authorizes technical planning within that scope.

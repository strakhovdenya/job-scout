# ADR-002: Next.js web and a finite Worker

**Status:** Accepted

## Context

The UI needs server routes and the scheduled workload needs its own lifetime.

## Alternatives considered

A NestJS backend adds a service for the current scope. An in-process timer ties workload progress to Web replicas.

## Decision

Use Next.js App Router and React/Material UI for Web and a bounded Node.js Worker for scheduled work. Web is intended for Cloud Run Service, Worker for Cloud Run Jobs. Independently scale or retry each.

## Consequences

Package and test two images. Worker persists pending work before future long-running operations and exits with an observable status. Real deployment is M5.

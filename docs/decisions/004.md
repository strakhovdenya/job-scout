# ADR-004: Google ADK TypeScript and model boundary

**Status:** Accepted

## Context

Screening needs structured validation and offline tests with provider choice kept outside the domain.

## Alternatives considered

Direct calls between apps and provider SDKs couple error handling and output. Python ADK would add another runtime.

## Decision

Use TypeScript ADK behind packages/agent and provider-independent Core schemas. Accept a configured model or ADK model instance and use model doubles in tests.

## Consequences

Verify actual TS APIs. Plan configurable quotas and eligible providers in M3. Production routing and evaluation are deferred.

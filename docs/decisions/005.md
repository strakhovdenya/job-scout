# ADR-005: One production project and bounded resource use

**Status:** Accepted

## Context

A personal application needs low operating overhead and explicit cost decisions.

## Alternatives considered

Multiple initial projects increase administration. Always-on infrastructure raises idle cost. Unbounded background work makes cost and recovery unpredictable.

## Decision

Plan one initial production Google Cloud project, with scoped service identities, idle scale-to-zero, finite runs, budgets and persistent pending work. Prefer eligible free allowances and verify regional pricing.

## Consequences

There is no guarantee of zero cost. Europe-west3 is a starting preference. Reassess separate staging, regional availability, TTL charges and actual provider allowances at the deployment milestone.

# Adr

Use for persistent decisions about boundaries, providers, failure policies, contracts, infrastructure, or process enforcement. Read the nearest entries in [docs/decisions](../../../docs/decisions/README.md) and search for an existing decision on the same topic. Use the [ADR template](../../../docs/templates/adr.md) and the next unused number only for a new decision.

Compare viable options against actual constraints and explain what would cause the choice to change. Record concrete consequences and verification. Keep proposals separate from accepted decisions and mark unverified assumptions. Review a draft against related ADRs with fresh eyes before accepting it. Preserve accepted history with a dated amendment or a superseding record, and update the index and architecture doc.

# ADR-001: Modular workspace and framework-independent core

**Status:** Accepted

## Context

JobScout needs one change surface with two delivery units and shared domain rules.

## Alternatives considered

Separate repositories duplicate contracts. A single application couples HTTP and scheduled lifecycles.

## Decision

Use a pnpm workspace. Put Zod contracts and pure rules in Core, with package public entry points and independent apps. This keeps types and validation shared without coupling Core to an SDK.

## Consequences

Package builds and source mode must agree. Import and cycle checks protect the boundary.
